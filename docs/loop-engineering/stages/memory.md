# 04 — Mémoire

## Finalité

Conserver les apprentissages du cycle sous une forme **sourcée, contextualisée et retrouvable**.

## Responsabilités

- extraire les faits utiles ;
- enregistrer la provenance et la date ;
- associer les faits au contexte et aux versions ;
- détecter les conflits et doublons ;
- conserver les décisions et leurs justifications ;
- rendre l'information réutilisable par les cycles suivants.

## Modèle minimal d'une connaissance

| Champ | Description |
|---|---|
| Identifiant | Référence stable |
| Type | Fait, décision, risque, hypothèse, preuve ou retour d'expérience |
| Contenu | Information structurée |
| Source | Origine vérifiable |
| Contexte | Projet, version, environnement et étape |
| Date | Date d'observation ou de décision |
| Confiance | Niveau de confiance explicite |
| Statut | Valide, invalidé, en conflit ou à confirmer |

## Règles

1. Une information non sourcée ne devient pas vraie par répétition.
2. Les conflits doivent être conservés jusqu'à résolution.
3. Une connaissance périmée doit être marquée, pas silencieusement supprimée.
4. La mémoire doit privilégier les éléments utiles aux décisions futures.
5. Les données sensibles doivent respecter les règles de conservation et d'accès.

## Anti-patterns

- journal brut sans structuration ;
- suppression des échecs ;
- conservation sans contexte temporel ;
- confusion entre préférence et fait ;
- mémoire illimitée sans stratégie de pertinence.
